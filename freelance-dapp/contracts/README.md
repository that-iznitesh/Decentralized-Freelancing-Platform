# Smart Contracts - Blockchain Teammate's Scope

Placeholder folder for `FreelanceMarketplace.sol` and any other Solidity
contracts. This is handled by the blockchain developer, not the frontend.

Expected responsibilities of this contract (per the brief):

- Store job ownership on-chain
- Handle escrow (locking client funds when a job is created/funded)
- Track which freelancer is hired for a job
- Handle milestone approval
- Release payment to the freelancer once a milestone is approved
